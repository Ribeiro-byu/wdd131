Contraste de Cores

Este elemento callout possui um contraste de cores ruim originalmente (#777 sobre #702963 dá uma proporção de 2.14:1), violando as diretrizes de acessibilidade WCAG AA e AAA. Alterando a cor do texto para branco (#ffffff) sobre o fundo roxo escuro (#702963), o contraste sobe para mais de 8.9:1, garantindo leitura nítida para todos.
